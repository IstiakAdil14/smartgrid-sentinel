# Literature Review

Standard grid load forecasting and stability models have historically used linear statistical approaches, such as AutoRegressive Integrated Moving Average (ARIMA). Although ARIMA models capture trends in stationary, single-variable series, they fail to model complex, non-linear relationships between meteorological changes and power demand dynamics. Classical machine learning classifiers, such as Random Forests and XGBoost, offer better performance by handling high-dimensional inputs. However, these tabular methods treat observations as independent, ignoring sequential patterns and temporal dependency.

To capture sequential relationships, recurrent neural networks like Long Short-Term Memory (LSTM) [6] and Gated Recurrent Units (GRU) [7] are frequently applied. These networks use persistent hidden states to carry sequential information across timestamps. Additionally, hybrid architectures like CNN-LSTMs [10] combine 1D convolutional operations for spatial feature extraction with recurrent nodes for sequence forecasting.

More recently, deep self-attention models have set new baselines in sequence modeling. The Informer [1] uses a ProbSparse self-attention mechanism to capture long-range dependencies with lower computational complexity, whereas PatchTST [3] breaks sequences into overlapping sub-series patches to preserve local correlations. However, current research seldom focuses on localized, Upazila-level load shedding forecasting, especially in areas with high grid instability, and rarely integrates machine learning predictions with rule-based text explanation layers.
